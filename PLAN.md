## Поточний стан (аудит 2026-08-11)

- Next.js 15 App Router, React 19, Tailwind CSS 4, `motion`, `qrcode`; усе — клієнтські компоненти (`'use client'`).
- Усі дані в `localStorage` браузера з крос-таб синхронізацією (`storage` events). Бекенду немає.
- Тримовний словник `TRANSLATIONS` у `lib/store.tsx`, тримовна модель даних (`*Ua/*En/*Hu`).
- Залишки шаблонного коду вже прибрано (README переписано; `metadata.json`, `.eslintrc.json`, `bun.lock` видалено; непотрібні env-змінні та невикористана залежність прибрані).

### Відомі баги (черга на виправлення)
- [ ] Замовлення гостя не доходять до власника (localStorage — на пристрої гостя). Вирішується переходом на Supabase.
- [ ] Пароль власника захардкоджений `admin123` і показаний на екрані входу (`OwnerCabinet.tsx:323`, `login.default_notice`).
- [ ] Кнопка «Зберегти страву» поза `<form>` — валідація `required` не спрацьовує; можна зберегти порожні описи/фото та ціну 0 (`OwnerCabinet.tsx:1397`, `:405`).
- [ ] `parseInt` для ціни обрізає копійки (`OwnerCabinet.tsx:1162`).
- [ ] Будь-який `?table=X` приймається без перевірки; у гостя немає вибору столу (переклад `cart.choose_table` не використовується).
- [ ] Видалення категорії не переназначає її страви (лишаються з мертвим `category` id).
- [ ] Статуси замовлень можна перемикати в будь-якому порядку (без валідації переходів).
- [ ] QR на екрані — зовнішній API `api.qrserver.com`, а завантаження — локальний `qrcode` (розбіжність + зовнішній запит).
- [ ] Немає обробки помилок: надсилання замовлення без `try/catch`, QR-download мовчки логує.
- [ ] Захардкоджені українські рядки в кабінеті власника в обхід i18n (статистика, «Стіл #», «Загалом:», «Каса» та ін.).
- [ ] Мертвий код: невикористані імпорти (`Printer`, `Eye`, `TrendingUp`, `Maximize2`, `ChevronRight`, `ImageIcon`), подія `qr_menu_orders_updated` без слухачів, стан `initialized` завжди `true` (гарди в ефектах — no-op).
