# QR Menu for Cafe

Мобільний веб-застосунок QR-меню для кафе: гості сканують QR-код на столі, переглядають меню та надсилають замовлення на кухню; власник керує меню, замовленнями, столиками та QR-кодами через особистий кабінет. Інтерфейс тримовний (укр / англ / угор).

## Можливості

- **Гостьове меню**: категорії, пошук за назвою/інгредієнтами, кошик із замовленням, коментар до замовлення, вибір столика через `?table=<id>`.
- **Кабінет власника**: вхід за паролем, моніторинг замовлень (статуси, звукове сповіщення), керування стравами та категоріями (з фото — завантаження або пресети), генерація та завантаження QR-кодів для столиків.
- **Локалізація**: повний словник `uk / en / hu`.

## Стек

- **Next.js 16** (App Router, Turbopack) + **React 19**
- **TypeScript 5**
- **Tailwind CSS 4** (+ `@tailwindcss/typography`)
- `motion` (анімації), `lucide-react` (іконки), `qrcode` (генерація QR)
- Дані зберігаються в `localStorage` браузера (бекенд Supabase планується — див. `PLAN.md`)

## Команди

| Команда | Опис |
|---------|------|
| `npm install` | Встановити залежності |
| `npm run dev` | Dev-сервер (http://localhost:3000) |
| `npm run build` | Продакшен-збірка (Turbopack) |
| `npm run start` | Запуск продакшен-збірки |
| `npm run lint` | ESLint (flat config) |

## Структура

```
app/            — layout, головна сторінка (перемикач «Гість / Власник»), 404
components/     — CustomerMenu (гостьовий вигляд), OwnerCabinet (кабінет власника), LanguageSwitcher
lib/            — store.tsx (контекст: дані, CRUD, переклади, localStorage), utils.ts
hooks/          — useIsMobile()
```
